# WhatsApp Vendas — réplica independente v1.2.0

Extensão Chrome MV3 para uso no WhatsApp Web.

## Conteúdo
- Painel lateral com abas Mensagens e Imagens.
- Balão redondo arrastável para abrir o painel.
- Mensagens locais em `messages.json`.
- 8 follow-ups em `FOLLOW-UP > Recebeu Cotação`.
- 8 follow-ups em `FOLLOW-UP > Não Recebeu Cotação`.
- Favoritos persistentes no navegador, usando a estrela ao lado de cada mensagem.
- 5 imagens locais na pasta `images/`.
- Visualização ampliada das imagens e cópia pelo WhatsApp Web.
- Seleção de áudio pelo computador e envio pelo mecanismo da extensão.

## Instalação no Chrome
1. Extraia este ZIP.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta `whatsapp-vendas-final`.
6. Abra/atualize o WhatsApp Web.

## Conteúdo editável
- Textos: `messages.json`
- Imagens/lista de nomes: `images.json`
- Arquivos de imagem: `images/`

O conteúdo funciona localmente e não depende do repositório externo original para carregar mensagens ou imagens.
